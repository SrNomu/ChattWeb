🚀 A desktop chat application built with Electron that allows multi-session access to WhatsApp Web.

---

## 🧠 About the Project

ChattWeb is an Electron-based application that simulates multiple chat sessions using WhatsApp Web.

It allows users to:
- Use multiple accounts simultaneously  
- Switch between sessions  
- Maintain independent environments for each account

## 📦 Installation

Before running the project, you need to install Node.js.

### 🧩 1. Install Node.js

Download and install Node.js from the official website:

https://nodejs.org/

- Choose the **LTS version**
- During installation, make sure to check:
  ✔ "Add to PATH"

After installation, restart your computer (recommended).

---

### 🧪 2. Verify installation

Open the Command Prompt (CMD) and run:
